🛒 Sistema de Gestión de Tienda Online

Este proyecto consiste en una aplicación de consola (o interfaz) diseñada para gestionar el inventario de una tienda online de manera eficiente. Permite administrar productos, controlar el stock en tiempo real y obtener métricas financieras sobre el valor del inventario.

🚀 Funcionalidades
El sistema implementa operaciones esenciales de gestión de datos:

Gestión de Inventario: Creación y almacenamiento de productos con atributos de nombre, precio y cantidad.

Búsqueda Inteligente: Localización rápida de productos por nombre, devolviendo detalles de precio y disponibilidad.

Control de Stock: Función específica para actualizar existencias de forma dinámica.

Eliminación de Registros: Capacidad para remover productos del inventario permanentemente.

Métricas de Negocio: Cálculo automático del valor total del inventario (Precio × Cantidad).

🛠️ Tecnologías Utilizadas
Lenguaje: [Ej. Python / Java / JavaScript]

Conceptos aplicados: Programación Orientada a Objetos (Clases, Métodos), Gestión de Estructuras de Datos.

📦 Estructura del Proyecto
El corazón del programa es la clase principal que gestiona la lógica:

Producto: Clase que define el modelo de datos.

Inventario: Clase encargada de los métodos de búsqueda, actualización y cálculo de métricas.
